## 📖 About

This repository documents my **DSA problem-solving journey**, built around a simple idea:

> Instead of memorizing solutions to individual problems, focus on recognizing the **underlying pattern** behind them. One pattern unlocks dozens of problems.

Every entry here includes the approach, the mistakes made along the way, what I learned, and how the solution evolved — not just a final answer dropped into a file.

```text
Problem → Understand → Identify the Pattern → Build the Approach
   → Code in C++ → Analyze Complexity → Practice Variations → Recognize the Pattern
```

---

## 🎯 Why Pattern-Based DSA?

Most DSA grinding fails because people memorize solutions instead of recognizing structure. A single pattern — like **Sliding Window** or **Two Pointers** — can solve dozens of seemingly unrelated problems once you know what to look for.

This repo is my attempt to build that recognition muscle, one pattern at a time.

## 🚀 How I Approach Each Problem

1. **Read & understand** — restate the problem in my own words before touching code
2. **Identify the pattern** — what structure does this problem share with ones I've solved?
3. **Design the approach** — pseudocode or a rough plan before implementation
4. **Implement in C++** — clean, working code
5. **Analyze complexity** — time & space, and whether it can be improved
6. **Note the mistakes** — what I got wrong first, and why
7. **Practice a variation** — a different problem using the same pattern
